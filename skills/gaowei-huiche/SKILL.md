# 高位回撤观测

## 什么时候用

- 想知道**当前哪些主流资产已经明显跌离历史最高价**，需要一个按回撤幅度排好的榜单；
- 想判断**某个资产当前价格下方有没有成交量堆出来的支撑区**、上方哪里有压力区；
- 想排查**深度回撤之后是接近支撑，还是仍然存在继续破位的风险**；
- 需要一份**数据来源可核实**（全部走币安官方公开资源）的回撤与成交分布结果。

## 什么时候不要用

- 想要**买卖信号或点位预测** —— 本技能只做客观观测与区间识别，不给方向性建议；
- 想看**链上数据、持仓分布、聪明钱流向** —— 这些不在本技能口径内；
- 想看**合约数据（持仓量、资金费率、多空比）** —— 本技能只走现货口径；
- 想要**分钟级或秒级的短线信号** —— 本技能的窗口是「全历史高点」+「近一年日线」。

## 四个数据通道

| 通道 | 数据来源 | 币种宇宙 | 口径与取舍 |
|---|---|---|---|
| `--live`（默认） | 币安官方公开行情接口 `data-api.binance.vision` | 动态：全市场 USDT 交易对按 24h 成交额排序 | 全历史 ATH（官方月线最高价）；速度最快 |
| `--skill` | **币安官方技能 binance + 官方 CLI** | 同上 | 与 `--live` 同源，但请求由官方 CLI 发起；未装 CLI 时如实回退并标注 |
| `--official` | 币安官方开源数据仓库 `data.binance.vision` | 同上 | 走官方月度日线归档 ZIP；ATH 只覆盖回溯窗口，**口径与上两个通道不同**，输出里会如实标注 |
| `--global` | 综合平台全市场口径（**非官方**） | 综合平台口径 | 只用于对照官方口径的差异，不代表官方数据 |

四个通道共用同一个自研引擎（`core/signals.py`），换的只是取数层。

## 命令示例

```bash
# 默认通道：官方公开行情，回撤榜前 20，并对回撤最深的 3 个币做成交分布分析
python agent.py

# 官方技能 + 官方 CLI 通道，输出纯 JSON
python agent.py --skill --json

# 官方开源数据仓库通道，回溯 24 个月
python agent.py --official --months 24 --top 12

# 只看指定币种
python agent.py --symbols BTC,ETH,SOL --depth 3

# 与综合平台口径对照
python agent.py --global --top 10

# 自然语言：直接说需求，自动选通道
python agent.py "看看哪些币回撤得最狠"
python agent.py "用官方开源数据看看 BTC 距最高还有多远"
python agent.py "用官方技能包看看 ETH" --json
```

`--json` 时 stdout 是纯 JSON，所有进度与说明都走 stderr，方便被其他程序直接消费。
另外 `--concurrency N` 可调整逐币下载的并发数（默认 8，上限 32）。

**自然语言参数的规则**：只在「没有显式给通道参数」时才用来选通道 —— 显式参数永远优先；
识别不出通道就沿用默认通道，**不会根据一句话去猜币种或改其他参数**。

## 输出字段

顶层：

| 字段 | 含义 |
|---|---|
| `source` | 实际走的通道：`live` / `skill` / `official` / `global` |
| `sourceLabel` | 通道的中文说明（直接写进报告用） |
| `requestedSource` | 只在「请求了 --skill 但回退」时出现，标明原本请求的是哪个通道 |
| `overview` | 回撤榜单，按回撤幅度升序（最深的最前面） |
| `zones` | 成交量分布与支撑压力，键是币安交易对 |
| `summary` | 汇总：最大回撤、平均回撤、深度回撤个数（≤ -70%） |
| `engine` | 固定为 `core/signals.py（自研）` |
| `honesty` | 本次结果必须一起交代的边界说明（**不准省略**） |

`overview` 每行：

| 字段 | 含义 |
|---|---|
| `symbol` | 币安交易对，如 `BTCUSDT` |
| `price` | 当前价格（官方快照 `lastPrice`） |
| `ath` | 历史最高价 |
| `athMonth` | 最高价出现的月份 |
| `athScope` | **ATH 的口径说明**，不同通道不一样，必须一起展示 |
| `drawdown` | 距最高价回撤百分比，负数 |
| `change_24h` | 24 小时涨跌幅 |
| `quoteVolume` | 24 小时成交额（计价币） |

`zones[交易对]` 每项：

| 字段 | 含义 |
|---|---|
| `current` | 当前价 |
| `profile` | 成交量分布，每个价格桶的成交量 |
| `peak_zone` | 成交量最密集的价格带 |
| `support` | 当前价下方的支撑位（最多 3 个，由近到远） |
| `resistance` | 当前价上方的压力位（最多 3 个，由近到远） |

## 算法口径

全部在 `core/signals.py`，纯规则、可复现：

1. **回撤** = `(当前价 - 历史最高价) / 历史最高价 × 100%`；
2. **历史最高价**：取官方月线 K 线的最高价列，跨全部月份取最大值。月线的最高价就是该月最高价，所以这个 ATH 是**精确值**，不是近似；
3. **成交量分布**：把窗口内的价格区间等分成 18 个桶，按**每日收盘价**落在哪个桶，就把当天的成交额累加到该桶；
4. **支撑位**：成交量分布中价格 ≤ 当前价的桶，按离当前价由近到远取最多 3 个；
5. **压力位**：价格 > 当前价的桶，同样取最多 3 个；
6. **峰值区**：成交量最大的那个桶的中位价。

第 3 步是「按收盘价归桶」的粗粒度近似 —— 它把一整天的成交额都算到收盘价所在的桶里。这是本引擎的既定口径，**不冒充精确的逐笔成交量分布**。

## 诚实边界

- **ATH 是币安现货口径**，基于币安官方月线最高价；与「全市场综合口径」的历史最高价可能略有差异，两者不可混用。
- **`--official` 通道的 ATH 不是全历史 ATH**，只是回溯窗口（默认 24 个月）内的最高价。要全历史 ATH 请用 `--live` 或 `--skill`。输出里的 `athScope` 会写明是哪个口径。
- **官方开源数据仓库是 T+1 归档**，最新一两天通常还没发布，缺失的月份会在 `monthsMissing` 里如实标出，不做补齐、不猜数。
- **现货快照不含持仓量**，所以本技能没有持仓量、资金费率、多空比这类合约维度。
- **`--global` 通道用的是综合平台数据，不是币安官方资源**，列出来只是为了对照。
- 本技能输出的是**观测结果**，不构成投资建议。
